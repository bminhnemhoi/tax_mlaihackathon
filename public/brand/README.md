# Tax Referee identity

The TR monogram shares a horizontal bar and open geometric bowl, with a diagonal R leg. It replaces the generic shield at brand touchpoints. The existing navy/lime palette and product typography stay consistent.

Files:
- `tax-referee-logo.png`: 512 × 512, transparent outside the navy tile; downloadable logo.
- `tax-referee-mark.png`: 96 × 96, compact UI asset.
- `/favicon.ico`: PNG-backed ICO with 16, 32 and 48 px entries.
- `/favicon-16x16.png`, `/favicon-32x32.png`: standalone favicon exports.
- `/apple-touch-icon.png`: 180 px on an opaque navy background for Apple devices.
- `/icon-192.png`, `/icon-512.png`: app icon exports.

Created with the built-in Imagegen tool, then resized/encoded using the project's existing Sharp dependency. Original generated file: 1254 × 1254 PNG with alpha. These are raster assets, not vector source files.
